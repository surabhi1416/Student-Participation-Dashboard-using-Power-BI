# Student-Participation-Dashboard-using-Power-BI
Designed an interactive Power BI dashboard analyzing student participation, department-wise engagement, and event-level trends using dummy institutional data.
Implemented data modeling, DAX measures, and slicers to dynamically visualize KPIs such as total participants, revenue generated, and event distribution.
Delivered actionable insights through bar, pie, and line charts, enabling clear comparison across departments, years, and event types.
